# БЛАТКОМ ’89 (BLATKOM ’89)

«Районные дела — серьёзные дела» / *District business is serious business*. Многопользовательский
2D-экшен с видом строго сверху для Telegram Mini Apps и браузеров: позднесоветский район, звери-
персонажи, до 10 игроков на карте в четырёх режимах — «каждый сам за себя», «красные против синих»,
захват флага и захват баз. Игра на двух языках — английском (с привкусом советского жаргона и нафталина:
talons, deficit goods, «Dossier») и русском; язык выбирается сам (Telegram/браузер) и переключается в
меню. Вывески на картах — по-русски; панель `/admin` — по-русски. Играть можно бесплатно, покупки
необязательны.

## Что внутри

| | |
|---|---|
| Игра | Phaser 3, вид сверху, 60 Гц симуляция; 14 персонажей (2 бесплатных — петух и пантера, 6 за уровень + талоны, 6 за алмазы; равные боевые характеристики); 32 ствола: 3 бесплатных (ПМ, монтировка, АК-47), 9 за талоны, 10 за алмазы, 10 редких из кейса (сайдгрейды, а не апгрейды); 7 видов снаряжения (Ф-1, дым, светошумовая, «коктейль Молотова», мина, C4, турель) и 6 модификаций (глушитель, коллиматор, оптика, лазер, рукоять, магазин) — у каждой плюс и минус |
| Карты | 7: Factory Checkpoint, Garage Cooperative, Soviet Courtyard и четыре по планам заказчика — Construction Site (Стройка), House of Culture (Дом культуры), Gastronom, City Hospital No. 3; в выборе карты — квадратные плитки: снимок карты настоящим рендером и под ним подпись в одинаковой полосе (размер шрифта общий, длинные названия не вылезают); на каждой карте — 14 точек появления, стойки флагов и базы A, B, C |
| Режимы | до 10 игроков: «каждый сам за себя» (до 50 очков); «красные против синих» (до 40 устранений команды, огонь по своим не проходит); **захват флага** — укради флаг со стойки соперника и донеси до своей, пока свой флаг на месте; несущий роняет флаг, когда его устраняют, свой упавший флаг возвращается касанием или сам через 15 с; до 3 захватов; **захват баз** — три базы A, B, C, флаг поднимается, пока внутри стоит только одна команда (6 с в одиночку, быстрее вдвоём-втроём), каждая база даёт команде очко в секунду; до 250 очков. Боты в тренировке играют на цель: воруют, охраняют, возвращают флаги, сопровождают несущего, берут базы |
| Очки и лут | устранение +2, помощь +1 (от 20 урона за 6 с до устранения); захват флага +6, возврат +2, кража +1, перехват несущего +1; взятие базы +3 каждому внутри. Оружие на точках, аптечки, «дефицит» — ящик с сильным стволом из Арсенала и полным боекомплектом (первый через 25 с, дальше раз в 35 с) |
| Мультиплеер | авторитарный сервер (WebSocket), предсказание и интерполяция, компенсация лага, комнаты по приглашению и быстрая игра, переподключение; **добор состава** — если людей мало, сервер дополняет матч своими игроками (ИИ тренировки) до 4 в «каждый сам за себя» и до 3 на 3 в командных режимах: быстрая игра стартует сама примерно через 10 с, комнату с друзьями хозяин запускает хоть в одиночку; в игре добранные ничем не отличаются от людей (клички, уровни, аватарки), в статистике и админке считаются только люди (`MATCH_FILL_BOTS`, [docs/NETCODE.md](docs/NETCODE.md) §2a) |
| Тренировка | офлайн-матч с 1–9 ботами в любом режиме — работает без сервера; любое оружие и снаряжение можно «примерить» |
| Меню и Арсенал | симметричное меню: «Районные дела» слева, справа персонаж, плитки «Досье» (кличка, уровень, кошелёк) и «Арсенал» с пистолетом; в Арсенале — примерочная: большой портрет персонажа с листов БЛАТКОМ с примеряемым стволом и он же «в игре» — живая модель из игровых спрайтов, стреляет по кнопке; иконки оружия одного размера; в выборе персонажа — «личное дело» с портретом |
| Звук | процедурные эффекты (WebAudio) и саундтрек меню «Hurt» (Infraction & Emerel Gray) — включается вместе с меню: сразу, где браузер разрешает звук без нажатия, иначе экран загрузки заканчивается кнопкой «▶ Играть»; в матче стихает; громкость в настройках, кнопка в углу меню |
| Аккаунты | Telegram (`initData` проверяется на сервере), гость в браузере, привязка почты с паролем (вход с другого устройства, сброс пароля письмом через Resend или одноразовой ссылкой от админа); гостю в браузере при входе — окно «Сохрани прогресс»: создать аккаунт на почту, войти в существующий или продолжить как гость (спросим снова через сутки) |
| Друзья и Топ-100 | клички уникальны (регистр, пробелы, Ё/Е и похожие кириллица/латиница не обманут; при вводе — проверка и свободные варианты); друзья по кличке, статусы «в сети / в лобби / в матче / не в сети», личные сообщения с непрочитанными и «✓✓», приглашение в свою комнату — у друга всплывает карточка «Зайти»; кнопка «Играть» рядом с другом создаёт комнату и зовёт его; Топ-100 по рейтингу, уровню и устранениям — только настоящие игроки с доигранным онлайн-матчем; рейтинг с 1000: ±16 за место, победу или поражение команды, −16 за уход |
| Экономика | талоны — за каждый онлайн-матч по устранениям и помощи (5 за устранение, 2 за помощь, 5 за доигранный матч, не больше 100); алмазы — за деньги (карта через Stripe, крипта через NOWPayments, 100 💎 = $1); Арсенал, кейс с редким оружием и кейс со скинами (10 советских покрасок — Берёзка, Гжель, Хохлома, Золото партии… — на любой из 32 стволов, только внешний вид; оба по 299 💎, без дублей); внутри Telegram покупки за деньги выключены (там нужны Telegram Stars — ещё не подключены). См. [docs/ECONOMY.md](docs/ECONOMY.md) |
| Прогресс | кличка, аватарка (24 пиксельных портрета от заказчика, выбор в «Досье» и профиле, её видят в лобби), уровень и опыт, рейтинг, достижения, история матчей (с изменением рейтинга), статистика; в демо — локальный профиль |
| Аналитика | `/admin`: DAU/WAU/MAU, D1/D7, воронка (посетители → аккаунт → матч → возврат, источники), экономика (талоны, алмазы, выручка, покупки, модификации, кейсы), карточка игрока с кошельком и платежами, начисления и ссылки сброса пароля (с аудитом), ошибки, CSV |

## Быстрый старт (разработка)

```bash
npm install                      # Node.js ≥ 22.12
cp .env.example .env             # DATABASE_URL, SESSION_SECRET, DEV_AUTH_ENABLED=true
npm run dev                      # сборка клиента в watch-режиме + сервер с перезапуском → http://localhost:8080
```
Без сервера: `npm run build:demo:single` собирает `apps/web/dist-demo/blatkom89-demo.html` — один файл
(код, графика, шрифты внутри), который открывается двойным щелчком или с любого хостинга; доступна
тренировка с ботами. Параметры `?play=offline&map=factory&bots=3` сразу запускают матч.

Управление: WASD/стрелки — движение, мышь — прицел, ЛКМ или пробел — огонь, R — перезарядка,
1/2/3, Q или колесо — оружие, G или средняя кнопка мыши — снаряжение, E — подобрать, Shift — шаг,
Tab — таблица, Esc — пауза. На телефоне: левый стик — движение, правый — прицел, кнопки огня,
перезарядки, смены оружия и снаряжения.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | разработка (клиент + сервер, автоперезапуск) |
| `npm run build` | production-сборка клиента (`apps/web/dist`) и сервера (`apps/server/dist`) |
| `npm run build:demo` | офлайн-демо без сервера (`apps/web/dist-demo`) |
| `npm run build:demo:single` | то же одним самодостаточным HTML-файлом (`blatkom89-demo.html`) |
| `npm start` | запуск собранного сервера |
| `npm run assets` | заново сгенерировать спрайты/тайлы/эффекты (`tools/art`) |
| `npm run typecheck` | TypeScript strict по всем пакетам |
| `npm test` | модульные + интеграционные тесты (нужен `DATABASE_URL_TEST`) |
| `npm run test:e2e` | браузерные E2E (Playwright): тренировка, сенсорное управление, онлайн-матч двух браузеров со снаряжением, режимы онлайн (захват флага в двух браузерах на английском и русском, быстрая игра по режиму), однофайловое демо (кличка, очки, «дефицит», опыт, захват флага и баз, Арсенал, русский язык), всё снаряжение против бота |
| `npm run db:migrate` / `db:status` | миграции PostgreSQL |
| `npm run admin:create` | создать администратора панели |
| `npm run lint` / `format` | ESLint / Prettier |
