# Картинки для v0.2.25 — промпты для ChatGPT

Как пользоваться: открой ChatGPT, приложи указанные образцы (файлы пришлю вместе с этим документом), вставь промпт из раздела. Готовую картинку сохрани под именем из заголовка (например, `case_deficit.png`) и пришли мне — разом или по частям. Всё встанет в игру без других правок; пока картинки нет, в игре остаётся то, что есть сейчас.

Если результат не тот, допиши в тот же чат:
- появился текст — «убери весь текст, буквы и цифры»;
- предмет обрезан — «весь предмет целиком, с отступами по краям»;
- не тот стиль — «стиль точно как на приложенном баннере: пиксель-арт, тёмно-бордовые тона, золотые акценты»;
- персонаж не похож — «персонаж должен точно совпадать с приложенной картинкой: морда, цвета, одежда».

Общее для всех: без текста, букв, цифр, логотипов и водяных знаков — надписи на русском и английском игра накладывает сама.
