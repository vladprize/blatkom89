# БЛАТКОМ ’89 (BLATKOM ’89)

«Районные дела — серьёзные дела» / *District business is serious business*. Многопользовательский
2D-экшен с видом строго сверху для Telegram Mini Apps и браузеров: позднесоветский район, звери-
персонажи, бои «каждый сам за себя» на 2–6 игроков. Интерфейс игры — на английском с привкусом
советского жаргона и нафталина (talons, deficit goods, «Dossier»); вывески на картах — по-русски;
панель `/admin` — по-русски. Играть можно бесплатно, покупки необязательны.

## Что внутри

| | |
|---|---|
| Игра | Phaser 3, вид сверху, 60 Гц симуляция; 14 персонажей (4 бесплатных, 5 за уровень + талоны, 5 за алмазы; равные боевые характеристики); 32 ствола: 4 бесплатных, 18 в Арсенале, 10 редких из кейса (сайдгрейды, а не апгрейды); 7 видов снаряжения (Ф-1, дым, светошумовая, «коктейль Молотова», мина, C4, турель) и 6 модификаций (глушитель, коллиматор, оптика, лазер, рукоять, магазин) — у каждой плюс и минус |
| Карты | 7: Factory Checkpoint, Garage Cooperative, Soviet Courtyard и четыре по планам заказчика — Construction Site (Стройка), House of Culture (Дом культуры), Gastronom, City Hospital No. 3 |
| Очки и лут | устранение +2, помощь +1 (от 20 урона за 6 с до устранения); матч до 50 очков. Оружие на точках, аптечки, «дефицит» — ящик с сильным стволом из Арсенала и полным боекомплектом (первый через 25 с, дальше раз в 35 с) |
| Мультиплеер | авторитарный сервер (WebSocket), предсказание и интерполяция, компенсация лага, комнаты по приглашению и быстрая игра, переподключение |
| Тренировка | офлайн-матч с ботами — работает без сервера; любое оружие и снаряжение можно «примерить» |
| Аккаунты | Telegram (`initData` проверяется на сервере), гость в браузере, привязка почты с паролем (вход с другого устройства, сброс пароля письмом через Resend или одноразовой ссылкой от админа) |
| Экономика | талоны — за онлайн-матчи; алмазы — за деньги (карта через Stripe, крипта через NOWPayments, 100 💎 = $1); Арсенал, кейс без дублей; внутри Telegram покупки за деньги выключены (там нужны Telegram Stars — ещё не подключены). См. [docs/ECONOMY.md](docs/ECONOMY.md) |
| Прогресс | кличка, уровень и опыт, достижения, история матчей, статистика; в демо — локальный профиль |
| Аналитика | `/admin`: DAU/WAU/MAU, D1/D7, воронка (посетители → аккаунт → матч → возврат, источники), экономика (талоны, алмазы, выручка, покупки, модификации, кейсы), карточка игрока с кошельком и платежами, начисления и ссылки сброса пароля (с аудитом), ошибки, CSV |

## Быстрый старт (разработка)

```bash
npm install                      # Node.js ≥ 22.12
cp .env.example .env             # DATABASE_URL, SESSION_SECRET, DEV_AUTH_ENABLED=true
npm run dev                      # сборка клиента в watch-режиме + сервер с перезапуском → http://localhost:8080
```
Без сервера: `npm run build:demo:single` собирает `apps/web/dist-demo/blatkom89-demo.html` — один файл
(код, графика, шрифты внутри), который открывается двойным щелчком или с любого хостинга; доступна
тренировка с ботами. Параметры `?play=offline&map=factory&bots=3` сразу запускают матч.

Управление: WASD/стрелки — движение, мышь — прицел, ЛКМ или пробел — огонь, R — перезарядка,
1/2/3, Q или колесо — оружие, G или средняя кнопка мыши — снаряжение, E — подобрать, Shift — шаг,
Tab — таблица, Esc — пауза. На телефоне: левый стик — движение, правый — прицел, кнопки огня,
перезарядки, смены оружия и снаряжения.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | разработка (клиент + сервер, автоперезапуск) |
| `npm run build` | production-сборка клиента (`apps/web/dist`) и сервера (`apps/server/dist`) |
| `npm run build:demo` | офлайн-демо без сервера (`apps/web/dist-demo`) |
| `npm run build:demo:single` | то же одним самодостаточным HTML-файлом (`blatkom89-demo.html`) |
| `npm start` | запуск собранного сервера |
| `npm run assets` | заново сгенерировать спрайты/тайлы/эффекты (`tools/art`) |
| `npm run typecheck` | TypeScript strict по всем пакетам |
| `npm test` | модульные + интеграционные тесты (нужен `DATABASE_URL_TEST`) |
| `npm run test:e2e` | браузерные E2E (Playwright): тренировка, сенсорное управление, онлайн-матч двух браузеров со снаряжением, однофайловое демо (кличка, очки, «дефицит», опыт), всё снаряжение против бота |
| `npm run db:migrate` / `db:status` | миграции PostgreSQL |
| `npm run admin:create` | создать администратора панели |
| `npm run lint` / `format` | ESLint / Prettier |

## Структура

```
apps/web          клиент (Phaser + DOM-меню) и панель /admin
apps/server       HTTP API, WebSocket-комнаты, PostgreSQL, аналитика, админка
packages/shared   общая симуляция, карты и коллизии, правила, протокол, схемы
tools/art         процедурный пайплайн графики → apps/web/public/assets
infra/            Dockerfile, Caddy, скрипт бэкапов (docker-compose.yml в корне)
references/       исходные референсы арт-директора (не используются как игровые экраны)
tests/e2e         браузерные сценарии Playwright
```
